# 🛒 Superstore Sales Dashboard — Power BI

## Overview
Interactive 3-page Power BI dashboard built on the 
Kaggle Superstore dataset (9,994 rows of US retail 
orders from 2014–2017).

## Pages
- **Page 1 — Executive Overview:** KPI cards, 
  monthly trend, regional sales, segment breakdown
- **Page 2 — Product Analysis:** Category comparison, 
  sub-category profitability matrix with conditional 
  formatting, sales vs profit scatter plot
- **Page 3 — Customer Drillthrough:** Per-customer 
  order history, monthly trend, shipping preferences

## Features
- DAX measures: Total Sales, Profit Margin %, 
  YoY Growth, Rolling Average
- Conditional formatting (red/green profit matrix)
- Drillthrough navigation
- Star schema with dedicated Date table
- Dynamic slicers (Year, Region, Category)

## Dataset
Kaggle Superstore Dataset — 9,994 rows
https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

## Tools Used
- Power BI Desktop
- Power Query (ETL)
- DAX
